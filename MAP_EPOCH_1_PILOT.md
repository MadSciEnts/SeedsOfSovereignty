# MAP: EPOCH I (Tiers 1–12) - The Pilot

## 1. Core Loop
- **Objective:** Exploration and survival. Navigate the "Void" to discover procedural wrecks, Essence clusters, and outposts.
- **Combat:** Twitch-based movement. Sub-tier weapon evolution drives early power spikes.

## 2. Weapon Sub-Tiers (Tier 1 Baseline)
Every major Tier in Epoch I follows an internal upgrade path:
- **(a) Proto:** Base weapon, slow fire rate.
- **(b) Refined:** Increased fire rate, same geometry.
- **(c) Advanced:** Multi-barrel configuration (Alternating Side Emission).
- **(d) Apex:** Maximum barrels/rate for the current chassis.

## 3. The Evolutionary Path (Verified)
- **T1-T4:** Interceptor -> Violet -> Carrier -> Sentinel (Twin-Stick).
- **T5-T8:** Bulwark -> Sentinel+ -> Wraith -> Dreadnought (Heavy Kinetic).
- **T9:** **Vanguard** (High-Energy/Beam Focus) - *In Progress*.
- **T10-T12:** Final Pilot stage evolutions leading to Epoch II transition.

## 4. Technical Specs for Epoch I
- **Camera:** Dynamic "Leash" follow-lock.
- **Floating Origin:** Snap world back to (0,0) at 10,000 unit threshold.
- **Viewport:** `ExtendViewport` ensures 1:1 aspect ratio.
- **Sensors:** Circular radar (1000u range).
- **Market:** Multi-offer weapon systems with visual data-link analysis.
