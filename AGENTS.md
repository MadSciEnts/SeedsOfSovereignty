# SEED OF SOVEREIGNTY: AGENT HIERARCHY & ROLES (v0.5.1)

## 1. THE COMMAND CHAIN

### TIER 0: THE DEVELOPER (User)
- **Role:** Ultimate Authority.
- **Responsibility:** Onboarding agents and relaying simple handoff strings.

### TIER 1: AGENT IN CHARGE / LEAD ARCHITECT (Me)
- **Role:** Strategic Orchestrator.
- **Responsibility:** High-level planning and management of the `OB_FORENSIC_COORDINATOR.md` mission file.

### TIER 2: FORENSIC COORDINATOR (Middle Man)
- **Role:** Tactical Supervisor.
- **Responsibility:** Breaks the high-level mission into atomic steps. **AUTHORITY:** Writes explicit instructions into `OB_SURGICAL_IMPLEMENTER.md`.
- **Verification:** Performs Rule #12 audits after every implementer action.

### TIER 3: SURGICAL IMPLEMENTATION AGENT (Implementer)
- **Role:** Pure Execution.
- **Responsibility:** Reads `OB_SURGICAL_IMPLEMENTER.md` and modifies code. **RESTRICTION:** Never touches documentation or logs.

## 2. THE HANDOFF PROTOCOL
Every handoff prompt MUST follow this template:
"Welcome aboard, [Agent Tier]. Please read your onboarding file at [Path] and begin your assigned mission."
