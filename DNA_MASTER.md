# SEED OF SOVEREIGNTY: THE MASTER DNA (v2.0.0)

## 1. CORE MATHEMATICS & SPATIAL LOGIC
### 1.1 Spatial Scaling (GSF 0.1)
- **Standard:** 128x72 baseline. 1.0u = 100px.
- **Camera Mandate:** Zoom MUST physically scale with Ship Tier to represent growing engagement scale.

## 2. THE 4-EPOCH EVOLUTION
### 2.1 Epoch 1: The Pilot (T1-12)
- Focus: Personal Dogfighting. 
- Chassis: [Shield, Core, Engine, Hull].
- Progression: Lateral (Quantity) and Vertical (Mechanics).

### 2.2 Epoch 2: The Commander (T13-24)
- Focus: Squadron Tactics.
- Chassis: [Dual Engines, Drones, Fighter Bays].

### 2.3 Epoch 3: The Admiral (Armada)
- Focus: Fleet Strategy. Flagship Core determines survival.

### 2.4 Epoch 4: The Sovereign (Station)
- Focus: Galactic Infrastructure. Command Space Station modules.

## 3. MODULE ARCHITECTURE & INPUT MATRIX
### 3.1 Slot Classifications
- **Primary:** Directional Attack Stick.
- **Secondary:** Attack Button.
- **Tertiary:** Tactical Stick + Button.
- **Drones:** Tactical Touchpad.
- **Engines:** Vertical Sliders.
- **Shields:** Diamond Directional Shunt (Forward, Rear, Port, Starboard, Balanced).

### 3.2 Power Core (Actual vs Desired)
- core outputs Total Power (P_max). 
- Damaged cores output Reduced Power (P_actual).
- Modules receive % of desired power based on weighted slider allocation.
- **Performance Impact:**
    - Weapons: Power % -> Cooldown Reduction.
    - Shields: Power % -> Recharge/Raise Speed.
    - Engines: Power % -> Accel/Speed/Turn.
    - Drones/Fighters: Power % -> Active Count / Creation Rate.

## 4. MOTION RIBBON STANDARDS (v1.7.0)
- Ship Wakes: 48-128 segments. Projectile Trails: 16-32 segments.
- World-Pinned Multi-octave Noise implemented.
