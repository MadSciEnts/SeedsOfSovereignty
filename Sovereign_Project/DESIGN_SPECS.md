# SOVEREIGN ENGINE: DESIGN & DISPLAY SPECS

## 1. VIRTUAL RESOLUTION
- **Target:** 640 x 360 (16:9).
- **Scaling:** Draw to a Bitmap, then scale to screen height with letterboxing for wide displays.

## 2. HUD SAFE ZONES
- **Motion Zone (Left 30%):** Joystick / Navigation.
- **Action Zone (Right 40%):** Command Matrix / Sliders.
- **Status Gutter (Top 10%):** Vital Stats.

## 3. ORIENTATION
- **Landscape:** Standard flight mode.
- **Portrait:** Tactical Menu mode. UI expands to 60% bottom; Game View shrinks to 40% top.
