\# DEBUG: THE DEV NEXUS



\## 1. The Console

\- \*\*Overlay:\*\* A slide-down terminal (tilde key or triple-tap on Android).

\- \*\*Commands:\*\* - `/tier \[X]`: Instantly evolve player to Tier X.

&nbsp; - `/spawn \[EnemyID]`: Force-spawn a specific entity.

&nbsp; - `/god`: Toggle invincibility.

&nbsp; - `/warp \[Sector]`: Jump to a different procedural seed.



\## 2. Visual Profiler

\- \*\*Draw Calls:\*\* Monitor `SpriteBatch` performance.

\- \*\*ECS Audit:\*\* List all active `Fleks` systems and their processing time (ms).

\- \*\*Memory:\*\* Real-time graph of Heap usage to catch Android memory leaks.
