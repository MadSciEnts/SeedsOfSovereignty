\# UI STYLE GUIDE: The Visual Identity



\## 1. Aesthetic: "Tactical Minimalism"

\- \*\*Vibe:\*\* A high-end military terminal meets alien technology.

\- \*\*Lines:\*\* Thin, precise 1-2px lines. No thick or rounded "cartoon" borders.

\- \*\*Typography:\*\* Use a monospaced font (e.g., 'JetBrains Mono' or 'Roboto Mono') for data and a bold, wide-kerning sans-serif for headings.



\## 2. Animation Philosophy

\- \*\*Instant Response:\*\* UI elements must react within 0.05s of a touch.

\- \*\*Layered Menus:\*\* When a menu opens, the background game world should blur (Gaussian Blur) or darken (Dim) to pull focus.

\- \*\*The "Aperture" Opening:\*\* Windows should not "fade" in; they should slide open from a central horizontal slit like a camera aperture.
